# 权利要求书

## 一种基于压力传感器的自适应多模式触觉控制方法及系统

### 权利要求

**1.** 一种基于压力传感器的自适应多模式触觉控制方法，其特征在于包括以下步骤：

**步骤S1：压力数据获取**
- 通过压力传感器阵列获取压力分布数据；

**步骤S2：接触状态检测**
- 计算压力分布数据的最大压力值和接触面积；
- 当最大压力值大于预设压力阈值且接触面积大于预设面积阈值时，判定为有效接触状态；

**步骤S3：压力中心计算**
- 利用加权质心算法计算当前压力中心位置：
```
cop_x = Σ(pressure_data * X) / total_pressure
cop_y = Σ(pressure_data * Y) / total_pressure
```
其中，X、Y为坐标网格，total_pressure为总压力值；

**步骤S4：起始位置管理**
- 当检测到首次有效接触且起始压力中心位置为空时，将当前压力中心位置设置为起始压力中心位置；
- 当检触状态从有效变为无效时，重置起始压力中心位置为空；

**步骤S5：位移向量计算**
- 计算当前压力中心位置与起始压力中心位置的位移向量：
```
displacement_vector = [current_cop[0] - initial_cop[0], current_cop[1] - initial_cop[1]]
```

**步骤S6：控制模式自适应切换**
- 计算位移向量的欧几里得距离：`distance = sqrt(dx² + dy²)`；
- 基于距离值进行分段判断：
  - 当distance < 第一阈值时，设定为空闲模式；
  - 当第一阈值 ≤ distance < 第二阈值时，设定为摇杆模式；
  - 当distance ≥ 第二阈值时，设定为触控板模式；

**步骤S7：控制输出计算**
- 根据当前控制模式计算相应的控制输出：
  - 空闲模式：输出零控制信号；
  - 摇杆模式：基于位移向量方向和距离计算速度控制信号；
  - 触控板模式：基于累积位移计算位置控制信号。

**2.** 根据权利要求1所述的方法，其特征在于，所述步骤S7中摇杆模式的控制输出计算包括：

**步骤S7-1：方向向量归一化**
- 计算位移向量的幅值：`magnitude = sqrt(dx² + dy²)`；
- 当幅值大于预设最小值时，计算归一化方向向量：
```
direction = displacement_vector / magnitude
```

**步骤S7-2：速度映射计算**
- 将位移距离映射到速度因子：
```
distance_ratio = (magnitude - joystick_threshold) / (touchpad_threshold - joystick_threshold)
distance_ratio = clip(distance_ratio, 0.0, 1.0)
speed_factor = distance_ratio^0.7
```

**步骤S7-3：目标速度计算**
- 计算目标速度向量：
```
target_velocity = direction × speed_factor × max_speed × sensitivity
```

**步骤S7-4：速度平滑处理**
- 对速度向量进行指数移动平均平滑：
```
current_velocity = smoothing_factor × last_velocity + (1 - smoothing_factor) × target_velocity
```

**3.** 根据权利要求1所述的方法，其特征在于，所述步骤S7中触控板模式的控制输出计算包括：

**步骤S7-5：位移缩放**
- 对位移向量进行灵敏度缩放：
```
scaled_displacement = displacement_vector × touchpad_sensitivity
```

**步骤S7-6：累积位移计算**
- 对缩放后的位移进行阻尼累积：
```
accumulated_displacement = accumulated_displacement × damping_factor + scaled_displacement × (1 - damping_factor)
```

**步骤S7-7：位置输出**
- 基于累积位移计算目标位置：
```
target_position = current_position + accumulated_displacement
```

**4.** 根据权利要求1所述的方法，其特征在于，所述第一阈值设定为0.01-0.1个像素单位范围内，所述第二阈值设定为5-20个像素单位范围内，且所述阈值可根据传感器特性和应用场景进行动态调整。

**5.** 根据权利要求2所述的方法，其特征在于，所述速度因子采用0.5-1.0次幂范围内的非线性映射，优选0.7次幂，以提供更平滑的控制响应特性，且所述次幂值可根据具体应用需求进行调整。

**6.** 根据权利要求2所述的方法，其特征在于，所述平滑因子设定在0.7-0.95范围内，优选0.8-0.9范围，以平衡响应速度和稳定性，且所述平滑因子可根据系统实时性要求进行自适应调整。

**7.** 根据权利要求3所述的方法，其特征在于，所述阻尼因子设定在0.1-0.5范围内，优选0.2-0.4范围，以防止累积位移的无限增长，且所述阻尼因子可根据传感器精度和用户操作习惯进行动态配置。

**8.** 根据权利要求1所述的方法，其特征在于，所述压力中心计算步骤中，仅使用压力值大于压力阈值的有效压力点进行加权质心计算。

**模式切换模块**，用于根据位移距离自适应切换空闲、摇杆、触控板三种控制模式；
