### 图6：摇杆模式速度控制算法流程图

**图示内容**：
```
          [摇杆模式启动]
                │
                ▼
      [计算位移向量和距离]
                │
                ▼
       [距离 < 1e-6?] ────是────▶ [应用速度衰减]
                │                      │
                否                      ▼
                │              [返回衰减后位置]
                ▼
      [计算归一化方向向量]
      direction = vector/|vector|
                │
                ▼
         [距离到速度映射]
      ratio = (dist-min)/(max-min)
      factor = ratio^0.7
                │
                ▼
        [计算目标速度向量]
      target_vel = direction × factor 
                × max_speed × sensitivity
                │
                ▼
         [速度平滑处理]
      current_vel = α×last_vel + 
                   (1-α)×target_vel
                │
                ▼
        [计算新位置并输出]
      new_pos = current_pos + current_vel
                │
                ▼
            [输出结果]
```

### 图7：触控板模式位置控制算法流程图

**图示内容**：
```
        [触控板模式启动]
                │
                ▼
      [计算COP位移向量]
      displacement = current - initial
                │
                ▼
         [位移幅值限制]
      if |displacement| > max_range:
          displacement *= max_range/|displacement|
                │
                ▼
         [应用灵敏度缩放]
      scaled_disp = displacement × sensitivity
                │
                ▼
         [累积位移处理]
      accumulated = accumulated × damping + 
                   scaled_disp × (1-damping)
                │
                ▼
        [计算目标位置]
      target_pos = current_pos + accumulated
                │
                ▼
         [位置边界检查]
      target_pos = clamp(target_pos, min, max)
                │
                ▼
            [输出结果]
```

## 附图制作要求

### 绘图标准
1. **图形规范**：采用黑白线条图，线条粗细统一
2. **标注清晰**：所有关键部件和数据流都要有明确标注
3. **比例协调**：各部分大小比例要合理，便于理解
4. **专业排版**：采用工程制图标准，符合专利附图要求

### 文件格式
- **提交格式**：PNG或JPG，分辨率不低于300DPI
- **尺寸要求**：A4纸大小，210×297mm
- **文件命名**：图1_系统架构图.png、图2_算法流程图.png等

### 制作工具推荐
1. **专业工具**：Visio、AutoCAD、Illustrator
2. **在线工具**：Draw.io、Lucidchart
3. **简易工具**：PowerPoint、Keynote（配合专业模板）
